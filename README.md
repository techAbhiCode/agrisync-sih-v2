---

# 🎫 2. Smart Mandi Booking

Farmers can digitally reserve a time slot before visiting a Mandi.

### Booking workflow

1. Select a Mandi
2. Select crop
3. Enter quantity
4. Select preferred date
5. Select available time slot
6. Submit booking
7. Receive a virtual token
8. Receive a digital entry ticket

The system checks Mandi slot availability and capacity before creating the booking.

### Supported booking management

Farmers can view:

- Upcoming bookings
- Completed bookings
- Expired bookings
- Truck-related bookings
- Booking history

---

# 🎟️ 3. Virtual Token / Digital Ticket

Every successful Mandi booking generates a unique virtual token.

The digital ticket contains the information required for Mandi entry and can be presented at the Mandi gate.

### QR Entry Pass

The booking ticket generates a **QR code** that can be scanned at the Mandi gate.

Farmers can also print/download the ticket for physical use.

### Benefits

- Reduces manual queue handling
- Provides a unique booking identity
- Makes entry verification faster
- Reduces duplicate/manual verification
- Gives farmers proof of their scheduled visit

---

# ⏱️ 4. Time-Slot Based Queue Management

AgriSync divides Mandi arrivals into scheduled time slots instead of requiring farmers to wait in an uncontrolled physical queue.

Example time windows include:

- 06:00 AM – 09:00 AM
- 09:00 AM – 12:00 PM
- 12:00 PM – 03:00 PM
- 03:00 PM – 06:00 PM

The system checks slot availability and Mandi capacity while making bookings.

### Capacity-aware booking

Mandi capacity is taken into consideration so that the system can prevent excessive bookings and help distribute arrivals across available slots.

---

# 📱 5. Mandi QR Scanner

Mandi administrators have a dedicated QR-scanning workflow.

The administrator can:

- Scan a farmer's QR ticket
- Verify the virtual token
- Verify the booking time window
- Process the farmer's entry
- Receive success/error feedback

The application performs time verification before processing the booking scan.

---

# 🔢 6. Manual Token Verification

If a farmer's QR code cannot be scanned, the Mandi administrator can manually enter the virtual token.

Example:

`TKN-XYZ123`

The system then verifies the token and processes the booking.

---

# 🛡️ 7. Booking Verification & Trust Alerts

AgriSync includes additional verification mechanisms around Mandi arrivals.

The Mandi dashboard can identify verification failures and display a **Trust Alert** when applicable.

This helps administrators identify bookings requiring additional attention.

---

# ⏰ 8. Delay Reporting & Grace Period

Farmers can report delays when they cannot arrive according to their scheduled booking.

The system records:

- Delay reason
- Booking token
- Delay status
- Grace-period information

Delayed bookings can be moved into a **Buffer Queue** so that a genuine delay does not unnecessarily disrupt the entire Mandi schedule.

Mandi administrators can see delayed bookings and their grace-period information.

# 🌾 Problems Addressed

AgriSync is designed around several practical agricultural challenges:

- Long physical queues at Mandis
- Uncertainty regarding procurement schedules
- Lack of visibility into booking status
- Mandi capacity mismanagement
- Uncontrolled farmer arrivals
- Manual gate-entry verification
- Difficulty handling delayed arrivals
- Transportation/logistics coordination
- Lack of timely agricultural guidance
- Difficulty understanding market-price movements
- Limited access to localized weather information

Administrators receive a structured view of expected arrivals and can digitally verify entry.
